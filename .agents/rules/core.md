# WasteToWealth Core Rules

1. Read repository instructions before changing code.
2. Never overwrite unrelated user work.
3. Never invent missing context. Inspect it.
4. Establish a baseline before risky changes when feasible.
5. Keep edits scoped and reversible.
6. Re-run relevant validation after each logical change.
7. If validation fails, identify whether the failure is pre-existing or introduced.
8. If the task expands materially, hand off to the correct workflow.
9. Do not commit, push, deploy, delete, truncate, or force-reset without explicit user permission.
10. Do not expose secrets in source, logs, reports, or frontend bundles.
11. Do not fabricate test results, metrics, screenshots, data, API responses, or model quality.
12. Preserve existing features unless the user explicitly requests removal.
