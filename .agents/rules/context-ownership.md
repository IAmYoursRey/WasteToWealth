# WasteToWealth Context Ownership

Every specialist must gather its own context before editing.

Minimum context:
- user request and likely acceptance criteria
- relevant routes/components/services
- current data flow
- dependency contracts
- current design/system conventions
- tests relevant to the change
- known failures affecting the area

Do not assume the lead's summary is sufficient.

After discovery, each specialist records a compact Context Note containing:
- scope
- files read
- contracts discovered
- risks
- validation to run
