# UI CHANGE

1. intent
2. recon
3. ui-designer reads current UI map and target implementation
4. ui-designer updates UI memory plan
5. frontend implements
6. ui-designer re-reads changed UI and updates .agents/context/ui-map.md
7. tester validates desktop/mobile behavior
8. reviewer checks visual and structural consistency
9. reporter summarizes

The UI map is a living source of truth for future UI changes.
